# Tender routing and formatting notes

Source: session where the user asked for two different model-generated tender outlines and then fixed Word formatting on the output.

## Routing note
- Use multiple workers/models for the same tender scope when the goal is to avoid similar drafts.
- Keep the factual scope aligned but vary section ordering, granularity, and prose style.

## Formatting note
- For Word body text on macOS, the installed Chinese face name that rendered correctly in this session was `宋体-简`.
- Direct paragraph/run formatting on body text was more reliable than relying on style definitions alone.
- Reopen the `.docx` after saving to confirm the render.
