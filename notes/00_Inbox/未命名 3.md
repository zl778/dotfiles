按照你的环境（Windows 11 Mini + WSL2 Ubuntu 26.04 + MacBook Pro），完全可以通过 SSH 登录到 WSL。这样以后就不用每次先打开 Windows Terminal，再进入 WSL 了。

方案有三，采用了“直接SSH到WSL”
## **第一步：安装 OpenSSH Server**
	WSL 中执行：
		sudo apt update
		sudo apt install openssh-server
	确认监听：
		`ss -tln | grep 22`
## **第二步：启动 ssh 服务**
	Ubuntu 26.04 默认可能没有一直运行 `sshd`。
	sudo service ssh start
	sudo service ssh status
	Active: active (running)
## **第三步：从 Windows 转发端口**
	在管理员 PowerShell：
	listenaddress=0.0.0.0
	listenport=22 
	connectaddress=172.28.20.238
	connectport=22
## **第四步：Windows 防火墙**
	PowerShell 管理员：
New-NetFirewallRule `
    -DisplayName "WSL SSH" `
    -Direction Inbound `
    -Protocol TCP `
    -LocalPort 22 `
    -Action Allow

## **第五步：Mac 登录**
	ssh zl@192.168.26.xx
