# Hermes 主 Agent 任务下达模板

以后只需要对主 Agent Hermes 下任务，不需要分别对 Researcher / Engineer / Navigator 等子角色下任务。

## 通用模板

帮我完成【任务】。
目标是【你想达到的结果】。
限制条件是【时间 / 工具 / 格式 / 范围】。
如果需要拆分，你自己分配给合适的子 agent。
最后把结果整理给我。

## 最简模板

帮我处理【任务】，最后给我一个可直接使用的结果。

## 场景模板

### 1. 查资料类

帮我查一下【主题】。
重点看【关注点】。
请帮我整理成简明结论，并标出来源或依据。

### 2. 编程类

帮我实现 / 修改【功能】。
当前情况是【现状】。
希望结果是【目标】。
如果需要，你自己拆解并安排执行。
最后给我可运行的结果和修改说明。

### 3. 排障类

帮我排查【问题】。
现象是【报错 / 异常】。
我已经做过【尝试过的步骤】。
请先判断最可能原因，再给出排查步骤和修复建议。

### 4. 网页 / 浏览器类

帮我在网页上完成【操作】。
目标网站 / 页面是【地址或名称】。
需要完成【登录 / 下载 / 提交 / 查看】。
请你自己安排浏览器操作，完成后把结果告诉我。

### 5. 写作类

帮我把【材料】整理成【文档类型】。
风格要求是【简洁 / 正式 / 适合汇报 / 适合发群】。
重点突出【要点】。
最后输出可直接发送 / 保存的版本。

### 6. 综合类任务

帮我完成【总目标】。
这件事可能需要查资料、写代码、操作系统或浏览网页。
你自己拆任务并分配子 agent。
最后给我一个统一的结果和建议。

## 固定结构

1. 做什么
2. 要达到什么效果
3. 有什么限制
4. 需要什么输出格式

## 简版口令

帮我处理【任务】，你自己拆解并分配，最后给我可直接用的结果。

## 记住这 4 个关键词

- 任务
- 目标
- 限制
- 输出
